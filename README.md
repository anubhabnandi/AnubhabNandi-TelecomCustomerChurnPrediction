# Customer Churn Prediction Using Data Analytics and AI

Project Overview

This project focuses on analyzing telecom customer data and predicting whether a customer is likely to leave or continue using a service.

The project uses data analytics, visualization, and machine learning techniques to identify patterns associated with customer churn. A Random Forest Classifier is used to predict customer churn based on historical customer information.

- Clean and preprocess the dataset.

Dataset

The project uses the IBM Telco Customer Churn dataset.

Dataset source:

https://raw.githubusercontent.com/IBM/employee-attrition-aif360/master/data/WA_Fn-UseC_-Telco-Customer-Churn.csv

The dataset contains approximately 7,000 telecom customers and includes information such as:

- Customer tenure
- Monthly charges
- Total charges
- Contract type
- Internet service
- Phone service
- Payment method
- Customer demographics
- Churn status

The dataset is loaded directly from the public source in the Jupyter Notebook.

Machine Learning Model

The project uses the Random Forest Classifier for binary classification.

The model predicts two possible outcomes:

- Customer stays
- Customer churns

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
